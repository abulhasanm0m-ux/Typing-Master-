👥 বন্ধু ও লিডারবোর্ড

লগইন, বন্ধু সিস্টেম ও গ্লোবাল লিডারবোর্ড চালু করতে ফ্রি Firebase সেটআপ করুন (১০ মিনিট, একবারই):

  • console.firebase.google.com-এ Gmail দিয়ে login → Add project → যেকোনো নাম দিন → Create
  • Project হোমে Web (</>) আইকন ক্লিক করুন → অ্যাপের নাম → Register করুন
  • যে config code দেখাবে সেটা কপি করে Kimi-কে পাঠান — আমি গেমে বসিয়ে ফাইল দিয়ে দেব
  • Authentication → Sign-in method → Google → Enable
  • Firestore Database → Create database → Start in test mode
  • Firestore → Rules ট্যাবে নিচের code দিয়ে Publish:
    • rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /users/{u} { allow read, write: if true; }
    match /reqs/{r} { allow read, write: if true; }
  }
}
